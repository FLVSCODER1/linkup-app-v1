# LinkUp v0.7.0-beta.7

## Secure event cover images

- Adds one optional cover image to event creation and editing.
- Shows covers in the event feed and event details with a branded gradient fallback.
- Lets hosts replace or remove a cover and removes stored covers when an event is deleted.
- Leaves multi-image galleries, carousels, lightboxes, and gallery motion for Phase 10.

## Performance and accessibility

- Accepts JPEG, PNG, and WebP source images up to 8 MB.
- Resizes images in the browser to fit within 1600×900 and converts them to WebP before upload.
- Limits stored images to 2 MB and lazy-loads them from authenticated object URLs.
- Treats the cover as decorative because all essential event information must remain in the event fields.

## Security

- Stores a private Firebase Storage path in Firestore rather than a long-lived tokenized download URL.
- Limits reads to verified students who can access the associated event under its school or district visibility.
- Limits uploads, replacements, and deletes to the verified event host.
- Rejects non-WebP uploads, oversized files, forged owner/event metadata, and all undeclared Storage paths.
- Extends Firestore's strict event schema to validate event-scoped cover paths.

## Deployment

- Deploy both database rule sets with `firebase deploy --only firestore:rules,storage`.
- Apply `storage.cors.json` to each Storage bucket before browser testing authenticated image reads.
- Preview and production Firebase projects must each receive their own rules and CORS configuration.

## Testing

- Adds unit coverage for file format, source size, and event-scoped path generation.
- Adds Storage Emulator coverage for host uploads, verification, file metadata, content type, and school isolation.
- Runs Firestore and Storage emulators together in the permanent validation workflow.

## Review checklist

- Create an event with a JPEG or PNG cover and confirm the optimized image appears in the feed and detail page.
- Replace and remove the cover from the edit page.
- Confirm a student at the same school can view the cover.
- Confirm students at another school cannot read a school-only cover.
- Confirm district-event covers follow district visibility.
- Delete a covered event and confirm its Storage object is removed.
- Confirm an event without a cover uses the branded fallback without errors.
