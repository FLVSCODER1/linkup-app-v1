# LinkUp v0.7.0-beta.10

## Fixed

- Loads the private draft workspace through a verified, owner-scoped server
  endpoint instead of relying on browser Firestore rules that can drift from
  the repository between Firebase deployments.
- Keeps draft responses private by verifying the Firebase ID token and
  restricting the Admin SDK query and response to the authenticated host.
- Preserves newest-first draft ordering and local date formatting.

## Validation

- Added regression coverage for owner filtering, published-event exclusion,
  and newest-first draft ordering.
