# LinkUp v0.7.0-beta.8

## Summary

Moves event cover images from unavailable Firebase Storage to Cloudinary's
no-credit-card free plan while preserving the host-only upload experience.

## Changes

- replaces Firebase Storage uploads, reads, deletes, rules, emulator config,
  and client initialization with Cloudinary
- adds an authenticated server endpoint for event-cover upload and deletion
- verifies that the caller is a verified LinkUp user and the event host before
  accepting an image operation
- accepts JPEG, PNG, WebP, HEIC, and HEIF source photos
- compresses covers to WebP with a JPEG fallback for iOS browser compatibility
  and enforces a 2 MB server limit
- prevents Firestore clients from inserting or changing arbitrary cover URLs
- stores only validated Cloudinary HTTPS URLs and event-scoped public IDs
- adds privacy guidance beside the image picker
- adds deterministic signature tests and Firestore anti-forgery coverage

## Required Vercel variables

Configure these values for Preview before testing and for Production before
promotion:

- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`

The API secret must remain server-only and must never use a `NEXT_PUBLIC_`
prefix.

## Deployment

Firebase Storage is no longer required. Deploy Firebase configuration with:

```sh
npx firebase-tools@14.27.0 deploy --only firestore:rules --project <project-id>
```

## Validation

- unit tests cover source-image validation and Cloudinary request signatures
- Firestore rules prevent clients from forging cover-image fields
- type checking, linting, production build, and Firestore emulator tests remain
  release gates
