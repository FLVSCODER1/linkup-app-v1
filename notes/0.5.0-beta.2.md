# LinkUp 0.5.0-beta.2

Released: August 6, 2026

## Fixed

- Return existing test profiles to onboarding when their new private name fields
  have not been completed.
- Preserve existing display names as the default first-name value during the
  onboarding migration.
- Stop the Events and Profile pages from loading forever when an API or
  Firestore request stalls; both now fail after ten seconds with a recovery
  action.
- Load and save Profile data through the authenticated server profile API so
  private surname data remains separate from public profiles.
- Show a real school-specific empty state when no upcoming events are available.
- Keep the Events page subtitle accurate while the profile is loading.

## Changed

- Explain that onboarding interests help match students with people who enjoy
  similar activities.
- Remove the redundant Events link from the dropdown menu.
- Reuse the same authenticated profile client on the login, Events, and Profile
  pages.

## Verification

- Existing-profile migration and request-timeout tests: passed.
- Complete unit suite: 30 tests passed.
- ESLint, TypeScript, and the production Next.js build: passed.
- Live Vercel Preview onboarding review: pending.
