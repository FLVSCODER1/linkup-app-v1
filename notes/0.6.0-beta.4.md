# LinkUp 0.6.0-beta.4

## Fixed

- Allow an exact Firebase-console admin UID to finish and edit its profile
  using the school already assigned to its own user document when its verified
  email domain is outside the student school directory.
- Keep the admin exception scoped to the stored email, district, and school;
  normal student accounts remain restricted to approved school domains.
- Return the stored district ID to profile setup so a provisioned admin can
  recover from the unsupported-domain screen and save its private last name.

## Verification

- Added tests for the admin assignment exception, including non-admin,
  mismatched-email, and incomplete-assignment rejection cases.
