# LinkUp v0.7.0-beta.3

## Authentication landing page

- Replaced the black login card with a responsive, mobile-first LinkUp landing
  page using the proposed indigo, coral, periwinkle, and warm-white palette.
- Added the product hook and concise school-verification cues without committing
  a logo before the brand mark is selected.
- Improved form semantics, keyboard focus states, autocomplete hints, loading
  labels, and accessible status messaging.

## Separate account creation

- Moved account registration from the login page to `/signup`.
- Changed **Create account** into a real link from login to signup.
- Added password confirmation and focused validation tests.
- Preserved Firebase school-domain checks, email verification, session
  persistence, profile setup routing, and existing login behavior.

## Branding

- No logo asset is included in this release. Logo concepts are being reviewed
  separately before one is added to the application.
