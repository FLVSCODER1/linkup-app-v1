# LinkUp 0.7.0-beta.1

## Added

- Reusable event form with start/end times, location, category, description,
  capacity, and RSVP deadline.
- Draft saving plus host-only editing, duplication, publishing, and deletion.
- Host information and capacity/deadline details on event pages.
- Host access to their own drafts without exposing drafts to other students.

## Safety

- Student-created events remain restricted to the creator's verified school.
- Ownership, school, district, and visibility remain immutable after creation.
- Drafts stay out of the public event feed.

## Verification

- Unit coverage for event input, time ordering, deadlines, and capacity.
- Firestore emulator coverage added for host-only draft access.
- Full lint, typecheck, test, and production-build validation.
