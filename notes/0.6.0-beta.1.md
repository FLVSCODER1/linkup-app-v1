# LinkUp 0.6.0-beta.1

Released: August 6, 2026

## Added

- Add a server-only Firebase admin boolean at `admins/{uid}.isAdmin`.
- Show an orange Admin section in the dropdown only to authorized accounts.
- Add Join requests and ICS requests links for administrators.
- Let verified students submit official school calendar URLs for review.
- Add an ICS review queue with preview, approve, and reject actions.
- Convert approved requests into active school-scoped calendar sources with an
  audit record of the reviewing administrator.

## Security

- Keep admin records, calendar requests, and calendar sources inaccessible to
  Firestore clients.
- Require server-side admin authorization on every review and preview endpoint.
- Restrict calendar sources to HTTPS, reject credentials and private-network
  hosts, revalidate redirects and DNS results, cap downloads at 2 MB, and use a
  ten-second fetch deadline.
- Remove direct calendar preview/import access from ordinary accounts.

## Verification

- Admin capability, calendar URL, and Firestore rules source checks: passed.
- Complete unit suite: 42 tests passed.
- ESLint, TypeScript, and the production Next.js build: passed.
- Firestore emulator execution: pending because the local emulator download was
  blocked by the workspace network approval boundary.
- Live Vercel Preview review: pending.

## Firebase setup

Create an `admins` document whose ID is the account's Firebase Authentication
UID, then add a Boolean field named `isAdmin` with the value `true`. LinkUp does
not provide an in-app control for granting or revoking this permission.
