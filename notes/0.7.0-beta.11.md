# LinkUp v0.7.0-beta.11

## Added

- Adds an explainable Stage A recommendation engine using explicit interests,
  school scope, time relevance, and a small new-event boost.
- Adds deterministic daily discovery inventory so newly published events can
  earn exposure without unstable random ordering.
- Adds a bounded diversity reranker to reduce repetitive categories, hosts,
  times, and similar titles in the feed.
- Adds short recommendation reasons to the event response for future UI use.

## Security and privacy

- Moves feed loading behind a verified, authenticated server route.
- Rechecks school and district visibility, publication state, moderation,
  event time, and imported-calendar suppression before any event is scored.
- Explicitly excludes drafts, cancelled events, suppressed events, public
  events, other schools, and other districts from recommendation candidates.
- Keeps responses private and uncached.

## Deliberately deferred

- Collaborative filtering, social proof, impression tracking, and historical
  behavioral profiling remain disabled until LinkUp has enough consented,
  representative usage to validate them safely.

## Validation

- Adds unit coverage for scoring, deterministic discovery, deduplication,
  feed filling, diversity, hash normalization, and visibility boundaries.
- Validated with the complete unit suite, ESLint, TypeScript, and a production
  Next.js build. This release does not change Firestore rules.
